# NaRégua Rio

Sistema de agendamento de barbearias.

## Sobre o projeto

O NaRégua Rio é um sistema desenvolvido para facilitar o agendamento de serviços em barbearias.

A plataforma permitirá que clientes encontrem barbearias, escolham um barbeiro e realizem agendamentos de acordo com os horários disponíveis.

As barbearias poderão gerenciar seus profissionais, horários e agendamentos.

## Funcionalidades

### Cliente

 Criar uma conta e fazer login.
 Encontrar barbearias disponíveis.
 Escolher uma barbearia.
 Escolher um barbeiro.
 Consultar horários disponíveis.
 Realizar agendamentos.
 Visualizar e cancelar seus agendamentos.

### Barbeiro / Proprietário

 Cadastrar e gerenciar a barbearia.
 Cadastrar barbeiros.
 Definir horários de atendimento.
 Visualizar a agenda.
 Gerenciar e cancelar agendamentos.

### Administrador

 Gerenciar usuários.
 Gerenciar barbearias.
 Gerenciar barbeiros.
 Gerenciar agendamentos.
